GÉO 3 – Les grands fleuves de France

1. Qu'est-ce qu'un fleuve ?
Un fleuve est un cours d'eau qui se jette dans une mer ou dans un océan.

2. Les quatre grands fleuves
• La Loire se jette dans l'océan Atlantique.
• La Seine se jette dans la Manche.
• La Garonne se jette dans l'océan Atlantique.
• Le Rhône se jette dans la mer Méditerranée.
La Loire est le plus long fleuve de France.

À retenir
Une rivière se jette dans un autre cours d'eau ; un fleuve se jette dans la mer.
